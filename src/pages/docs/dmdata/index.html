Project DM-D.S.S

防災気象情報を提供するAPIサービス

Project DM-D.S.S とは

Project DM-D.S.S は、個人によって運営されている、多様な防災気象情報を提供する有料APIサービスです。

公式サイト arrow_forward

特徴

  • 高速な情報配信

    WebSocket API により、リアルタイムで情報を取得できます。

  • 高い信頼性

    Project DM-D.S.S が提供しているアプリケーションは予報業務許可（地震動）を取得しており、気象庁のガイドラインに沿った運用が行われているため、データ配信の信頼性が高いです。

  • 多様な情報

    緊急地震速報、地震情報、津波情報、気象警報、天気予報など、多様な防災情報を提供しています。

対応アプリケーション

Project DM-D.S.S からのデータ取得に対応している、おすすめのアプリをご紹介します。
※ アプリ利用者が個別に Project DM-D.S.S と契約をすることで利用可能となります。

  • EEW Client by DMDATA.JP

    Project DM-D.S.S が制作・提供している緊急地震速報アプリです。
    日本の緊急地震速報をリアルタイムで確認でき、ユーザーが設定した地点の予想震度・主要道到達までの時間・長周期地震動階級を表示します。予報業務許可（地震動）第237号。
    Windows, macOS に対応しています。
    また、EEW Client by DMDATA.JP 専用プランも提供されています。

    © DMDATA.JP
    arrow_forward

  • JQuake

    日本の緊急地震速報、地震履歴、津波情報、NIED強震モニタをリアルタイムで確認できます。
    Windows, macOS, Linux に対応しています。
    また、JQuake 専用プランも提供されています。

    © François LN
    arrow_forward

  • KyoshinEewViewer for ingen

    日本の緊急地震速報、地震情報、津波情報、NIED強震モニタをリアルタイムで確認できます。
    Windows, macOS, Linux に対応しています。

    © ingen084
    arrow_forward

  • EarthQuickly for Windows

    日本の緊急地震速報、地震情報、津波情報、NIED強震モニタをリアルタイムで確認できます。
    Windowsに 対応しています。
