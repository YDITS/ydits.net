YDITS について

利用者に最適な防災情報を迅速に提供する

YDITS (ワイディッツ) は、利用者の皆様に最適な防災情報を迅速に提供することを目標に、アプリ開発などを行っている防災サービスです。

防災の力で社会をもっと安全にする

私たちは、日常生活の中で地震・津波・噴火などの災害に直面することがあります。災害発生時に必要不可欠なのが、正確で迅速な防災情報です。
YDITSの運営者『よね/Yone』は、「防災の力で社会をもっと安全にする」という想いを持って運営を行っています。

アプリ

いま発表されている緊急地震速報、現在地の予想震度と主要動到達カウントダウン(警報対象の場合)、直近の地震情報の履歴、台風の予想進路図、雨雲レーダーを表示します。 Webアプリケーションなのでインストールすることなく、どこでも、すばやく防災情報を確認できます。

YDITS for Web double_arrow

YDITS API

防災情報をアプリケーションなどに組み込みやすいように設計された開発者向けのAPIです。当方サーバーとクラウドサーバーを併用し、エッジ処理やCDNよる配信を活用することで、サーバーをシステム的かつ地理的に冗長化し、大規模災害や障害が発生しても継続して情報を伝達するよう構築しています。

このAPIは現在開発段階のベータ版です。より高速で多様な情報の配信に取り組んでいます。
