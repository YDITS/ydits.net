YDITS API

YDITS が提供する防災情報パブリックAPI

防災情報をアプリケーションなどに組み込みやすいように設計された開発者向けのパブリックAPIです。オンプレミスとクラウドサーバーを併用し、エッジ処理やCDNよる配信を活用することで、サーバーをシステム的かつ地理的に冗長化し、大規模災害や障害が発生しても継続して情報を伝達するよう構築しています。

このAPIは現在開発段階のベータ版です。より高速で多様な情報の配信に取り組んでいます。

[2026年10月1日]
このAPIは現在開発段階のベータ版です。配信の遅延や停止が発生する場合があります。
現在利用できるエンドポイントは【緊急地震速報（警報）】のみです。

[2026年10月1日]
緊急地震速報のポーリング間隔は最短でも 1000ミリ秒=1秒以上、その他のエンドポイントは最短でも 30秒以上 である必要があります。
サーバーに対して高負荷を与えるような利用・実装はお控えください。
また、バグやエラーによりそのような動作になっていないか十分にお確かめください。

[2026年10月1日]

  • 現在 VXSE51, VXSE52, VXSE53, VXSE61, VXSE62 エンドポイントへの対応を進めています。
  • 緊急地震速報（警報）と 緊急地震速報（地震動予報） については、同一エンドポイントへの統合を予定しています。
  • 緊急地震速報については、WebSocket接続への移行を予定しています。

配信データ

  • 緊急地震速報（警報） →
    Earthquake Early Warning (EEW) - Warning
  • 【準備中】緊急地震速報（地震動予報） →
    Earthquake Early Warning (EEW) - Forecast
  • 【準備中】震度速報 →
    Earthquake Information (Seismic Intensity)
  • 【準備中】震源に関する情報 →
    Earthquake Information (Hypocenter Information)
  • 【準備中】震源・震度に関する情報 →
    Earthquake Information (Hypocenter and Seismic Intensity Information)
  • 【準備中】顕著な地震の震源要素更新のお知らせ →
    Significant Earthquake Hypocenter Element Update Notification
  • 【準備中】長周期地震動に関する観測情報 →
    Long-Period Ground Motion Observations Information
  • 【準備中】津波警報・注意報・予報 →
    Tsunami Warning / Advisory / Forecast

サーバー構成

  • api2.ydits.net: Cloudflare Workers

  • api3.ydits.net: オンプレミス (自宅サーバー)

情報取得先

本APIは、各データを気象庁から直接取得しています。

  • 気象業務支援センター (JMBSC)

    緊急地震速報は、気象庁の『地震活動等総合監視システム (EPOS)』から提供され、気象業務支援センターの『緊急地震速報配信システム』から分岐配信される電文を直接取得しています。
    JMBSC と YDITS の間は IP-VPN による接続を行っています。

    • VXSE43: 緊急地震速報（警報）

    • VXSE45: 緊急地震速報（地震動予報）

  • 気象庁 防災情報XMLフォーマット電文（PULL型）

    防災気象情報は、気象庁ホームページで提供される『防災情報XMLフォーマット電文 (PULL型)』から電文を直接取得しています。

    • VXSE51: 震度速報

    • VXSE52: 震源に関する情報

    • VXSE53: 震源・震度に関する情報

    • VXSE61: 顕著な地震の震源要素更新のお知らせ

    • VXSE62: 長周期地震動に関する観測情報

    • VTSE41: 津波警報・注意報・予報

    • VTSE51: 津波情報

    • VTSE52: 沖合の津波観測に関する情報

    • VYSE50: 南海トラフ地震臨時情報

    • VYSE51: 南海トラフ地震関連解説情報

    • VYSE52: 南海トラフ地震関連解説情報

    • VYSE60: 北海道・三陸沖後発地震注意情報
