YDITS API

YDITS が提供する防災情報API

  • 緊急地震速報（警報） →
    Earthquake Early Warning (EEW) - Warning
  • 緊急地震速報（地震動予報） →
    Earthquake Early Warning (EEW) - Forecast
  • 【準備中】震度速報 →
    Earthquake Information (Seismic Intensity)
  • 【準備中】震源に関する情報 →
    Earthquake Information (Hypocenter Information)
  • 【準備中】震源・震度に関する情報 →
    Earthquake Information (Hypocenter and Seismic Intensity Information)
  • 【準備中】顕著な地震の震源要素更新のお知らせ →
    Significant Earthquake Hypocenter Element Update Notification
  • 【準備中】長周期地震動に関する観測情報 →
    Long-Period Ground Motion Observations Information
  • 【準備中】津波警報・注意報・予報 →
    Tsunami Warning / Advisory / Forecast

情報元

  • Project DM-D.S.S

    • VXSE43: 緊急地震速報（警報）

  • 気象庁 防災情報XMLフォーマット電文（PULL型）

    • VXSE51: 震度速報

    • VXSE52: 震源に関する情報

    • VXSE53: 震源・震度に関する情報

    • VXSE61: 顕著な地震の震源要素更新のお知らせ

    • VXSE62: 長周期地震動に関する観測情報
